GitHub Pages & Google Drive Setup Guide

Step 1: Free Hosting on GitHub Pages

  1. Create a new GitHub repository (e.g., yunikon-auto-logs).
  2. Upload this single index.html file to the root of the repository.
  3. Go to Settings → Pages, select branch main and folder / (root), then click Save.
  4. Your live HTTPS URL (e.g., https://username.github.io/yunikon-auto-logs/) will be ready in 60 seconds!

Step 2: Connect Google Drive Cloud Database (100% Free)

  1. Open console.cloud.google.com and create a free project named Yunikon Auto DB.
  2. Go to APIs & Services → Library, search for Google Drive API, and click Enable.
  3. Go to OAuth consent screen → Choose External → Add your Gmail address under Test users.
  4. Go to Credentials → Create Credentials → OAuth client ID → Web application.
  5. Under Authorized JavaScript origins, add your GitHub Pages URL (e.g., https://username.github.io) and/or http://localhost.
  6. Copy the generated Client ID, click Google Drive in the top bar of this app, paste it, and click Connect Google Drive!
